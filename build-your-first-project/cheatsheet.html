What a Project is

Instructions (how to do the job) + files (what to know and copy). Every chat in the Project starts with both.

Claude can't see your other chats or the Project's name and description. Put what matters in the instructions or files.

When to make one

  • You keep re-explaining the same background or re-uploading the same files.
  • One Project per thing you make over and over.
  • Brainstorming something new? Use a fresh chat instead.

Build one in 4 steps

  1. Create: Projects, then New Project. Name it, skip "Use a folder", Create project. Context, +, Upload from device: one good example.
  2. Instructions: new chat in the Project (Chat, not Cowork), paste the Project Starter, answer one question at a time. Copy the box, then + next to Instructions, paste, Save instructions.
  3. Test: new chat, attach your starting point with +, ask for the thing. Paste the Check it prompt. Add its one sentence to the instructions, save, try again in a new chat.
  4. Share (optional): Share (top right), add a teammate, Can view. They see instructions and files, not your chats.

Every Project gets these 2 rules

"If information is missing, say so and ask. Never invent numbers or facts."

"Mark anything you inferred."

Your name is on it: 4 checks

  1. Read it, all of it.
  2. Understand it: could you explain it?
  3. Validate it: facts match, nothing hallucinated.
  4. Make it yours: your words. You'd sign it.

Keep it working

  • Use it 3 times this week.
  • It misses? Fix the instructions, not the chat. Add one specific sentence.
  • A chat drifts? Start a new one.
  • Great output? Add it to the files as an example.

Where things are

  • Projects: left sidebar.
  • Files: Project page, Context, +, Upload from device. Under 30MB.
  • Instructions: Project page, + next to Instructions.
  • Attach to one chat: + in the message box.
  • Shared with you: Projects, Shared with you tab.
  • Memory (optional): Settings, Memory.
Using work files? Follow your company's AI policy, and leave out personal details about customers.
